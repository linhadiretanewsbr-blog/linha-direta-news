## ⚡ COMANDOS DE ENTRADA RÁPIDA

**Admin Panel:**
- Login: Token Sanity (copiar de `Sanity Dashboard`)
- Atalho: https://linha-direta-news.vercel.app/admin

**Publicar Notícia:**
1. Abrir Admin Panel
2. Preencher: Título, Resumo, Conteúdo, Categoria, Autor
3. Colar URL da Imagem (do Cloudinary)
4. Clicar "Publicar Notícia"

**Editar Código:**
1. GitHub → Editar App.jsx
2. Commit com mensagem
3. Vercel faz deploy automático

**Upload de Imagem:**
1. Cloudinary → Media Library
2. Fazer upload
3. Copiar URL pública
4. Colar no Admin Panel
